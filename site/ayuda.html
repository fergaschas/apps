Cómo instalar

Mis apps no vienen de Google Play, de la Microsoft Store ni de la App Store, y los instaladores no llevan una firma comercial de Microsoft ni de Apple. Por eso tu sistema avisa la primera vez. Es normal: aquí tienes qué pulsar en cada caso.

Android Windows macOS Linux Comprobar el SHA-256

Android

  1. Pulsa Descargar para Android. Si el navegador avisa de que el archivo puede ser dañino, elige Descargar de todas formas.
  2. Abre el archivo .apk desde la notificación de descarga o desde la app Archivos.
  3. La primera vez, Android dice que por seguridad no puede instalar apps de esa fuente. Pulsa Ajustes, activa Permitir de esta fuente y vuelve atrás. Solo se hace una vez por navegador. Lo puedes desactivar después en Ajustes → Aplicaciones → Acceso especial de aplicaciones → Instalar aplicaciones desconocidas.
  4. Pulsa Instalar.

Si Play Protect avisa

Play Protect no conoce las apps que no están en Google Play y puede decir que la app es desconocida o que la ha bloqueado. Pulsa Más detalles y después Instalar de todas formas. Si te ofrece enviarla para analizarla, puedes aceptar o no: no cambia nada.

Actualizar

Las apps avisan solas cuando hay versión nueva. Si instalas a mano una versión nueva encima de la que tienes, conservas tus datos. Si Android dice que la app entra en conflicto con un paquete existente, la que tienes se firmó con otra clave (por ejemplo, una versión de desarrollo): desinstálala primero.

Los textos exactos cambian un poco según el fabricante y la versión de Android.

Windows

  1. Pulsa Descargar para Windows. Si Edge o Chrome dicen que el archivo no se descarga habitualmente, abre el menú del aviso (…), elige Conservar y después Conservar de todos modos.
  2. Abre el instalador .exe.
  3. Si aparece Windows protegió tu PC (SmartScreen), pulsa Más información y después Ejecutar de todas formas.
  4. Sigue el instalador. Normalmente el .exe instala solo para tu usuario, sin pedir permisos de administrador.

¿.exe o .msi?

Usa el .exe. El .msi es para instalaciones gestionadas o para todos los usuarios del equipo, y pide permisos de administrador.

Si Windows la bloquea sin opción de ejecutarla

En Windows 11, el Control inteligente de aplicaciones bloquea los programas sin una firma comercial y no ofrece Ejecutar de todas formas. Se configura en Seguridad de Windows → Control de aplicaciones y del explorador → Configuración de Control inteligente de aplicaciones. Desactivarlo afecta a todos los programas, no solo a este: piénsalo antes.

macOS

  1. Descarga el .dmg, ábrelo y arrastra la app a Aplicaciones.
  2. Abre la app. La primera vez, macOS (Gatekeeper) dice que no puede comprobar que esté libre de malware. Pulsa OK o Listo.
  3. Ve a Ajustes del Sistema → Privacidad y seguridad, baja hasta Seguridad y pulsa Abrir igualmente junto al nombre de la app. Confirma con tu contraseña o Touch ID.
  4. Vuelve a abrirla y pulsa Abrir. A partir de aquí se abre sin avisos.

En macOS 14 (Sonoma) y anteriores también vale clic derecho (o Control + clic) → Abrir sobre la app. Desde macOS 15 (Sequoia) solo funciona el paso de Privacidad y seguridad.

Si dice que la app está dañada

Si macOS dice que la app está dañada y no se puede abrir, es la marca de cuarentena de las descargas. Quítala desde la Terminal y vuelve a abrirla:

xattr -dr com.apple.quarantine "/Applications/Nombre de la app.app"

Linux

AppImage (cualquier distribución)

Dale permiso de ejecución y ábrelo:

chmod +x nombre-de-la-app-*.AppImage
./nombre-de-la-app-*.AppImage

En el gestor de archivos también vale: Propiedades → Permisos → Permitir ejecutar el archivo como un programa.

Si no arranca y menciona FUSE o libfuse.so.2, instala FUSE 2. En Ubuntu 24.04 o posterior es sudo apt install libfuse2t64, y en versiones anteriores, sudo apt install libfuse2.

.deb (Debian, Ubuntu, Linux Mint…)

sudo apt install ./nombre-de-la-app_*.deb

Con apt se instalan también las dependencias que falten. Para desinstalarla, usa sudo apt remove con el nombre del paquete.

Comprobar el SHA-256

Cada descarga muestra su SHA-256, una huella del archivo. Si calculas la huella del archivo que has descargado y coincide con la de la web, el archivo está completo y es exactamente el publicado. Es útil sobre todo si lo has descargado desde otro sitio o te lo han pasado.

Windows (PowerShell)
Get-FileHash .\nombre-del-archivo -Algorithm SHA256
macOS (Terminal)
shasum -a 256 nombre-del-archivo
Linux
sha256sum nombre-del-archivo
Android

Android no trae una herramienta para esto. Si descargas desde esta web no hace falta: la descarga llega cifrada desde GitHub, y las apps comprueban el SHA-256 solas cuando se actualizan.

PowerShell muestra la huella en mayúsculas y la web en minúsculas: da igual, se comparan las letras y los números.
